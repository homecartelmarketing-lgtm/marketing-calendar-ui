## 📌 Executive Summary

Resolved an issue where the **Output UI thumbnail** and media carousel for **Day & Night Story** (`Stories` category with idea `Day & Night`, `Day (D&N)`, or `Night (D&N)`) fetched the un-tagged raw photos instead of the deliverable photo with the **furniture item name text**.

### 🧩 The Problem
In Airtable Day & Night Story tables, the automation pipeline generates and uploads two separate sets of image attachments:
1. **`STORY - Day & Night (2)`**: Contains the raw, un-tagged Day and Night photos without product branding/labels.
2. **`Blended Image with Name text`**: Contains the photos with the **floating editorial item name tag** (generated by the local zero-cost YOLO-World tagging engine).

Previously, the media selection logic in [`lib/output-media.ts`](file:///c:/Users/User/Downloads/Marketing%20Output%20UI/lib/output-media.ts) and [`lib/output-mapping.ts`](file:///c:/Users/User/Downloads/Marketing%20Output%20UI/lib/output-mapping.ts) only read `STORY - Day & Night (2)`. As a result:
- The **Output UI gallery card thumbnail** (`slides[0]`) always displayed the untagged image.
- Downstream preview modals, schedule entries, and Meta publish calls defaulted to the untagged photos even when the tagged item name photos were completed in Airtable.

## 🛠️ Summary of Changes

### 1. [`lib/output-media.ts`](file:///c:/Users/User/Downloads/Marketing%20Output%20UI/lib/output-media.ts)
Updated `extractOutputMedia` for Day & Night stories and feeds to prioritize the tagged deliverable while maintaining backward compatibility with a fallback to `STORY - Day & Night (2)`:

```typescript
// BEFORE:
} else if (cat === "stories" && ((type.includes("day") && type.includes("night")) || type.includes("d&n") || type.includes("day (") || type.includes("night ("))) {
  selected = read("STORY - Day & Night (2)")
}

// AFTER:
} else if (cat === "stories" && ((type.includes("day") && type.includes("night")) || type.includes("d&n") || type.includes("day (") || type.includes("night ("))) {
  const tagged =
    read("Blended Image with Name text").length ? read("Blended Image with Name text") :
    read("Blended Image with Item Name").length ? read("Blended Image with Item Name") :
    read("Blended with Item Name").length ? read("Blended with Item Name") :
    read("Blended Image with Name").length ? read("Blended Image with Name") : []
  selected = tagged.length ? tagged : read("STORY - Day & Night (2)")
}
```
