# Session Log: 2026-10-01 — October Calendar Time Shift Fix

#daily-log

---

## 🎯 Goals & Objectives
- Find out why the October calendar looked wrong against `Content Calendar - October.pdf`.
- Confirm that re-importing October does not erase posts already scheduled.

---

## 🛠️ Work Done & Changes
1. **Root cause**: every planned time in `lib/content-data.json` was 8 hours early (timezone-dependent `Date` parsing from `xlsx`). It affected all months (91 days changed since `55a65a8`), not only October. See [[troubleshooting/calendar-import-timezone]].
2. **Parser fix**: `lib/workbook.ts` and `scripts/parse-calendar.mjs` read raw Excel serials (`cellDates: false`), convert time fractions to `H:MM`, and detect the year via `SSF.parse_date_code`. Planned statuses starting with "Scheduled" are normalized to "To Do".
3. **Data regenerated** from the latest `oct-calendar.xlsx` (now in `data/`): "One Light at a Time" name, correct times, chronological day keys. Output is identical under `TZ=UTC` and `TZ=Asia/Manila`.
4. **Tests**: added time and status regression tests in `tests/calendar-import.test.ts`.
5. **Live check and reschedule (production `homecartel-marketing-calendar-v2.vercel.app`)**: the production durable queue held jobs with the early times, so the runner would have published early. With the operator's approval, the 4 pending stories were rescheduled through the production `POST /api/schedules` (the same endpoint the UI uses; it cancels the old job, creates a new one and patches Airtable). The local app cannot do this because `.env.local` has no database URL (mock DB).
   - Oct 1 CTA Story (Pendant Light) `reci7Nk3ahZm3PZwj`: 13:00 -> 21:00
   - Oct 2 Collection Category (Pendant Light) `recjmnwscUJ7BzgsE`: 01:00 -> 09:00
   - Oct 2 Product Closeup w/ specifications (Chandelier) `recAuylHqQqgMlsa5`: 05:00 -> 13:00
   - Oct 2 CTA Story (Table Lamp) `recsXmSH4QO9NBObM`: 13:00 -> 21:00
   - Read-back: Airtable shows the new times; queue shows the old jobs `Cancelled` and new jobs `Scheduled` at 13:00 UTC Oct 1, and 01:00 / 05:00 / 13:00 UTC Oct 2.
   - Not touched: Oct 1 Day & Night (01:00) and Product Closeup w/ description (05:00) were already `Posted` early by the old times; they cannot be undone.
6. Verification: `npm test` (12 files, 110 tests), `npm run typecheck`, `npm run build` pass locally. This does not prove any live publication.
