## 🐞 Errors Encountered & Fixed
- **Timezone Offset Bug in Excel Parsing**: `anchor.getUTCMonth()` shifted month indices back by 1 (e.g. October became `2026-09-31`). Resolved by using canonical sheet-name mapping via `MONTH_NAMES.indexOf(name)`.
- **Single-Day Row Drop**: `isDayNumberRow` required `count >= 2`, which dropped rows containing only 1 day number (e.g. August 1 on a Saturday). Resolved by switching to column-by-column weekday block parsing.
